esphome-sma-sunnyboy

Read an SMA Sunny Boy solar inverter over Bluetooth with an ESP32 and send the data straight to Home Assistant.

View on GitHub

Features

  • No cloud, no Raspberry Pi

    An ESP32 within Bluetooth range of the inverter replaces SMA's cloud, Sunny Explorer and SBFspot.

  • Native Home Assistant device

    Data goes over the ESPHome API, and Home Assistant discovers the device automatically.

  • Energy dashboard ready

    The lifetime energy sensor plugs straight into the Home Assistant Energy dashboard.

  • Live AC and DC readings

    AC power, voltage, current and grid frequency, plus power, voltage and current for each DC string.

  • Inverter status

    Device status, grid relay, serial number, software version, temperature, operating time and Bluetooth signal.

  • Handles the night

    When the inverter turns off at dusk, values go unavailable (or 0 if you prefer) and the ESP32 reconnects when it wakes up.

  • Pure ESP-IDF Bluetooth

    Talks SMANET2+ over Bluetooth Classic SPP using the Bluedroid API directly, with no Arduino BluetoothSerial dependency.

  • Pick only what you need

    Every sensor is optional. Add just the keys you want to your ESPHome YAML.

Quick start

You need an original ESP32 (ESP32-WROOM or WROVER). S2, S3, C3, C6 and H2 chips have no Bluetooth Classic and won't work.

external_components:
  - source: github://jbflowerday/esphome-sma-sunnyboy
    components: [sma_bluetooth]

sma_bluetooth:
  mac_address: "00:80:25:xx:xx:xx"
  password: "0000"
  update_interval: 30s

The full sensor list and setup steps are in the README.

Built on the SMA protocol work of the SBFspot project.
